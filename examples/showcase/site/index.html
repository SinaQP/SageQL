Embedded chat reporting for Python backends

Ask for a report in plain language.
The model never writes the SQL.

SageQL turns a Persian or English request into a typed report specification, checks it against what the host registered and what the user may see, then writes a parameterized, read-only query itself. Below are real runs, stage by stage.

Source on GitHub PyPI

How a request becomes a report

  1. ModelExtract intent Picks registered measures, groupings, period and filters by ID, or asks a question.
  2. SageQLValidate Every ID must be registered and allowed for this user. Anything else is rejected.
  3. SageQLResolve Dates, Solar Hijri months and product names are resolved locally.
  4. SageQLCompile Writes the SQL with the user's row policy and bound parameters.
  5. SageQLExecute Read-only, with row, time and work limits. Rows never go back to the model.
