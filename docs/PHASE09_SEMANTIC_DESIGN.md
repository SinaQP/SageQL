# Phase 09 scoped semantic continuation design

Written before production repair. Preserve all original Phase 08 inputs/results;
promote A03/A04/A05/A06/A10/A11 and freeze six cross-domain replacements first.

The reproduction separates causes rather than assigning them to model quality:
single missing-detail fields can describe a year with a filter/group clarification
reason; equivalent imported/source dimensions look like a collision without a
selected fact; direction ranges and explicit direction conflict with top-N defaults;
ranked entity groupings and requested metric criteria need distinct roles;
plural quote-role wording is missed; a terminal correction modifier is parsed
as data. A11's unissued-reference rejection is correct for that bad grounding.

Keep public APIs and persistent session JSON. Extend only internal evidence with
bounded unresolved slot/reason pairs and equivalent grouping candidates. Select
one currently necessary question while retaining others. A confirmed answer
clears its own slot only; remaining original requirements and independent answer
clauses still apply. Reconstruct from bounded user evidence under current access,
never assistant-supplied values or arbitrary history. No global fixed question
order, persistent schema, new analytical capability or NLU dependency.

For an imported/source business dimension equivalence, defer fact selection until
intent chooses a permitted dataset. Preserve a disjunctive grouping requirement;
anchor its matching registered dimension and enforce it on every final provider
specification. Do not guess an unregistered measure or invent a relation.

An explicit direction governs a top/bottom row count; rank defaults apply when
direction is absent. Explicit contradictory directions still clarify. A ranked
registered entity is its grouping; choosing the requested criterion binds the
metric sort rather than retaining an obsolete dimension sort. Scoped grouping
replacement excludes the old dimension and requires the new one.

Extend existing quote-role grammar to plural terminology and explicit example
copulas. Direct quoted metric/operation selections and unknown quote roles retain
their separate meaning. Predicate quotes preserve exact source bytes. Strip a
terminal correction modifier only in an affirmative named-predicate correction;
quoted values remain data. Invalid/unissued references continue to fail closed.

Tests must precede repairs: original evidence, wrong and correct custom providers,
invalid/negative/question/contradictory answers, en/fa wording, multiple missing
details, independent instructions, both stores/reopen/replay/current metadata and
existing compiler/policy gates. No external model, production DB, automatic failed
DB retry, prompt rewrite, larger call budget, new stage or framework migration.
